# Changelog

All notable changes to Alap-Alap will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-XX

### Added
- Initial release of Alap-Alap
- Automatic sitekey detection from URLs
- Camoufox integration for anti-fingerprint browsing
- JavaScript bundle analysis for dynamic sitekeys
- Flask REST API server
- Invisible and visible captcha solving
- Natural mouse movement simulation
- Comprehensive error handling
- Full test suite
- Documentation

### Features
- **Sitekey Detection**: Multi-layered approach (URL params → HTML → JS bundles)
- **Browser Integration**: Camoufox for fingerprint resistance
- **Smart Solving**: Intelligent timing and movement patterns
- **API Server**: Ready-to-use REST endpoint

## [0.9.0] - 2024-01-XX (Beta)

### Added
- Beta testing phase
- Core solver functionality
- Basic sitekey detection

### Changed
- Improved mouse movement algorithms
- Enhanced error handling

## [0.8.0] - 2024-01-XX (Alpha)

### Added
- Initial prototype
- Proof of concept
